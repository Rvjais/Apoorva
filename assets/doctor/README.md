# Doctor portrait

Replace `doctor-placeholder.svg` with another SVG, or add your own JPG, PNG, or WebP image here and update the `.doctor-image` image `src` in `index.html`.

For example: `assets/doctor/dr-apurva-aditi.jpg`.

A portrait in a 4:5 aspect ratio works best. The page uses `object-fit: cover`, so the image keeps the same frame and alignment. Update the image alt text to describe the actual portrait when replacing the placeholder.
